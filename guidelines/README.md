# RDK-B Rust SIG Guidelines

This directory contains Rust engineering guidelines approved or maintained by the RDK-B Rust SIG.

Guidelines are intended to describe recommended practices for Rust components in RDK-B. They should be practical, portable, and suitable for embedded Linux systems.

## Available Guidelines

| Guideline | Description | Maintainer | Approval Status |
| --- | --- | --- | --- |
| [Continuous Integration](ci.md) | Recommended CI checks for Rust component repositories. | GitHub: @torrentius | Proposed |

## Status

Guidelines should not be treated as accepted SIG recommendations unless the decision is recorded in meeting notes or an approved proposal.

When adding or changing a guideline, include references to the meeting record, proposal, or discussion that established the recommendation.
