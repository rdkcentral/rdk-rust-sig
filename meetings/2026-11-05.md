5. Dependency update policy

6. CMF CVE review
Review of current component Cargo.toml files deferred due to time

## Decisions

1. The SIG approved adding the standard set of GitHub Actions workflows for RDK-B Rust repositories described in the [CI proposal](../proposals/ci.md).
2. The Stage 1 CI workflows will be recommended.
3. The SIG will evaluate multiple approaches to supporting older Rust compiler versions before making a recommendation.
